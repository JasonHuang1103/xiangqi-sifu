# Project-specific agent instructions

## Progress ledger

`PROGRESS.md` is the durable record of this project's evolution.

- Read `PROGRESS.md` before planning or modifying the project.
- Add intended work under **Active work** before implementation.
- Update the entry whenever requirements, assumptions, architecture, or the plan changes.
- Before committing, move completed work into the chronological log with outcomes, important decisions, affected areas, and verification results.
- Include the corresponding `PROGRESS.md` update in the same commit as every code, design, data, architecture, or plan change.
- Never record secrets, credentials, or personal game contents in the ledger.
